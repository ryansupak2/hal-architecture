## Editing the architecture diagram

The main artifact in this repo is `hal-architecture.svg` — an architecture diagram originally generated by draw.io.

Despite the draw.io header comment ("Do not edit this file with editors other than draw.io"), **we edit the SVG directly** as plain text. The file is a standard SVG that embeds the draw.io mxGraphModel in a `content` attribute, but all visual elements are regular SVG shapes, paths, and text that can be modified by hand.

When making changes:

- Read the SVG to understand the current structure before editing.
- SVG elements use `id` attributes derived from the draw.io cell IDs — preserve these to keep the diagram consistent.
- Coordinate changes should respect the existing `viewBox` and layout grid (the draw.io model uses a 10px grid).
- Icons referenced from the `icons/` directory are embedded as SVG `<image>` or `<use>` elements — keep paths relative.
- After editing, verify the SVG still renders correctly by opening it in a browser or image viewer.

The companion file `hal-invpay-arch.drawio` is the draw.io source but is not the primary editing target; the SVG is.
